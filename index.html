Electric / Endless run

どこまでも。

01 / JUMP

2回のタップで、
もうひと跳び。

空中でもう一度タップすれば2段ジャンプ。大きな崖を見きわめて、次の足場へ。

02 / COURSE

短い足場も、
長い陸地も。

一部の通常足場を、従来の最大幅の約1.5〜2倍に。短い足場や高低差との緩急を楽しみながら、次の着地点を見きわめましょう。

03 / RANKING

走った距離で、
ランキングに挑戦。

Game Centerの最長走行距離ランキングへの参加は任意。参加後の記録で挑戦でき、ニックネームと記録がほかのプレイヤーにも表示されます。未参加でも遊べます。
